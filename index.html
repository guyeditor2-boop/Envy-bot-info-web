Frequently asked questions.

How do I invite Envy to my server?

Replace YOUR_BOT_CLIENT_ID in this website with your Discord application's client ID, then use the Invite Envy link.

Can I configure the health monitor?

The bot's health feature is designed to let server staff select a channel and set a recurring update interval, subject to the commands and permissions enabled in your deployed version.

Where can I get help?

Join the support server using the Support Server links on this page.

Does every feature work automatically?

Some features need permissions, channel setup, or configuration. Review the bot's commands and logs after inviting it.
